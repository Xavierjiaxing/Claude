医疗器械生物相容性评价指南

1. 概述
生物相容性是医疗器械安全性的核心指标之一，依据 GB/T 16886 系列标准（等同采用 ISO 10993）进行评价。

2. 评价流程
2.1 材料表征
- 化学成分分析
- 物理化学性能测试
- 可浸提物/可沥滤物分析

2.2 生物学试验项目选择
根据器械与人体接触的性质和时间，选择相应的试验项目：
- 细胞毒性试验（GB/T 16886.5）
- 致敏试验（GB/T 16886.10）
- 刺激试验（GB/T 16886.10）
- 全身毒性试验（急性、亚慢性）（GB/T 16886.11）
- 血液相容性试验（GB/T 16886.4）
- 植入后局部反应（GB/T 16886.6）
- 遗传毒性、致癌性、生殖毒性（GB/T 16886.3）

3. 表面接触器械（接触时间 ≤24小时）的最低试验要求
- 细胞毒性
- 致敏
- 刺激

4. 外部接入器械（接触时间 24小时-30天）的附加要求
- 全身毒性（急性）
- 血液相容性（如接触循环血液）

5. 植入器械的附加要求
- 全身毒性（亚慢性）
- 植入后局部反应
- 遗传毒性
- 慢性毒性（如接触时间 >30天）

6. 评价报告要求
生物学评价报告应包含：
- 器械描述和预期用途
- 材料清单及化学表征数据
- 试验项目选择依据
- 试验结果和分析
- 综合安全性评价结论
